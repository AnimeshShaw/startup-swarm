# Startup Swarm (Codex, sequential mode)

Token-intensive multi-agent startup pipeline. On this host a single agent plays each role in turn, so isolation is by convention, not enforced. Ask the agent to use the `swarm-run` skill with your problem. A run uses many tokens and can take hours; there is no cost benchmark yet. Not tested on a live Codex host. Full documentation, security model and license (MIT): https://github.com/AnimeshShaw/startup-swarm
