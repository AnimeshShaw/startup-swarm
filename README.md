# Startup Swarm

Give an agent a business or product problem. A hierarchy of specialised, isolated agents runs a startup-style pipeline on it: **evidence → product definition → design (architecture, threat model, compliance, cost) → tested, audited code → release package**. Hooks, not prompts, enforce who can read and write what, and three human gates (evidence, design/cost, release) stop the run from sprinting past a bad premise.

```
/swarm:run  Build a tool that lets small clinics in India reduce no-shows
```

That is the whole interface. The swarm interviews you once if the brief is vague, then works for hours, and stops only at the three gates. Prefer no questions at all? `/swarm:god <problem>`.

> **Status: v0.1, unit-tested but not yet field-tested.** The runtime has 65 passing tests, was driven end to end with simulated hook payloads, and its hooks were probed once on a live headless Claude Code session. Interactive slash commands, a full multi-hour run, Windows, Codex and Cursor are not verified; see [docs/security-model.md](docs/security-model.md) for exactly what is and isn't verified. Read it before trusting an unattended run.

## Pick your mode

| | `/swarm:run` (guided, default) | `/swarm:god` (god mode) |
|---|---|---|
| Asks you | up to 5 batched intake questions, 3 gate sign-offs, rare blocking questions | nothing |
| Decides | with your sign-off at G1, G2, G3 | everything, logged in `.venture/state/autopilot-decisions.md` |
| Output is | a package you have approved at each gate | an **unvalidated hypothesis package** plus code. Labelled `EXPLORATORY` and `AUTOPILOT` |
| Use when | you will act on the result | you want a fast, cheap first draft to react to |

God mode cannot do customer discovery. Its "evidence" is desk research, so it ends at plausible, not proven. It also never deploys, spends money, or sends anything.

## Install

**Claude Code** (full experience, hook-enforced):
```
/plugin marketplace add AnimeshShaw/startup-swarm
/plugin install swarm@startup-swarm
```
**Codex** and **Cursor** get a reduced, convention-only mode (no hooks). Details and caveats: [docs/install.md](docs/install.md).

Requires Python 3.9+ on PATH (`python3` or `python`). No other dependencies.
