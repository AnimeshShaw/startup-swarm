# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas rather than people, and do not harass anyone. Maintainers may remove comments or contributions that violate this and may ban repeat offenders.

Report conduct concerns privately through GitHub's "Report content" feature or by contacting the maintainer via the email on their GitHub profile.
