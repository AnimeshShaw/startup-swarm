# Business model canvas as hypotheses

Fill the nine blocks (segments, value proposition, channels, relationships, revenue, key resources, key activities, partners, costs) as short statements, then add two columns: confidence (fact, estimate, guess) and the cheapest test.

Rules
- Start with one segment, not three. A canvas that serves everyone serves no one.
- The value proposition must name the job, the pain, and the measurable gain.
- Revenue: price, who pays, how often. Check against costs: if the unit economics need unrealistic volume, say so.
- Mark the three riskiest blocks. The evidence plan tests those first.
