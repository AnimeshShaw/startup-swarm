# Market sizing

1. Bottom-up first: number of reachable customers x realistic conversion x annual revenue per customer. Each input is tagged and sourced, or marked ESTIMATE with its basis.
2. Top-down second, only as a sanity check. If the two differ by more than 3x, explain which input is wrong.
3. Report SAM and SOM for the first 24 months, not just a headline TAM.
4. Give low, base and high cases. Never a single number.
5. State what you could not find. Analyst-report totals without a method are GUESS.
